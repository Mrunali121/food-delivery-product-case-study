# Mockups — Reorder & Live ETA Confidence

Low-fidelity wireframes (SVG, viewable directly on GitHub) showing the current
friction points identified in [user research](../../user-research.md) against
the redesigned flow specified in the [PRD](../../product-requirements-document.md).

| Screen | Shows |
|---|---|
| [`01-home-current.svg`](01-home-current.svg) | Current home screen — no reorder entry point |
| [`02-home-improved.svg`](02-home-improved.svg) | Redesigned home screen — one-tap reorder cards (FR-01, FR-02) |
| [`03-tracking-current.svg`](03-tracking-current.svg) | Current order tracking — static ETA range only |
| [`04-tracking-improved.svg`](04-tracking-improved.svg) | Redesigned tracking — live ETA + delivery stage (FR-04 to FR-06) |

These are intentionally low-fidelity wireframes, not visual design comps — the
goal is to communicate the structural change (what's on screen and why) to
engineering and stakeholders, not to finalize visual styling.
