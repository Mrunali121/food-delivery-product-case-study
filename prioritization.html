Prioritization (RICE)

Six candidates scored; two built first.

How the scoring works

Each candidate was scored with RICE: Reach (how many users per quarter) × Impact × Confidence ÷ Effort (person-months). The workbook uses live formulas, so changing an input re-ranks the list. The scores were workshopped with Engineering, Design and Support.

Result

RankFeatureRICEDecision
1Live ETA Confidence28.8Q2 - Built
2One-Tap Reorder25.5Q2 - Built
3Checkout Simplification5.6Q3 - Deferred
4Loyalty & Rewards Program3.0Q4 - Deferred
5In-App Courier Chat0.4Not prioritized
6Group Ordering / Bill Splitting0.3Not prioritized

The top two features target the two root causes found in research: the checkout ETA is not trusted, and reordering a favourite meal takes too many steps. Both are built in Q2; the rest are deferred or dropped.
